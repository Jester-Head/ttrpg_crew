# Appendix A, Glossary (Comprehensive)

| Term | Definition |
|---|---|
| **Aethos** | An ancient giant-kin race that predated the common era. Their burial grounds form the geological foundation of Gloamvere City. Disturbed ley lines and spirits produced the Era of Calamities. In modern Gloamvere, massive formations resembling ribs or vertebrae are embedded in the bedrock. |
| **Aethos Ranges** | Mountain or highland region in Arche where the giant-kin Aethos originally lived before their civilization fell. The burial mounds that became Gloamvere City's foundation were an extension of this territory. |
| **Aethos Substrate** | Stratum 3 of Kavath: the altered foundational layer beneath/around Gloamvere City where resonance, buried structures, and boundary effects concentrate. Memory behaves differently underground, it flows through corridors like water through aqueducts. |
| **Amalga (Tier 3)** | Procedural memory ("muscle memory"): fused skills and practiced routines that can be stored, traded, and loaded into people or constructs. |
| **Anchoring** | A preservation rite performed at a Thin Spot to halt degradation of a memory at its current state. Requires an Eidolon Compass, a catalyst memory, and proper site preparation. Cannot reverse degradation. |
| **Arche** | The Material Plane, the original world with continents, oceans, nations, weather, sunlight. Gloamvere City sat on lagoon islands at the mouth of the Vastus River. After displacement, the lagoon islands are simply gone. |
| **Archon (construct class)** | Classified/rumored construct class. Rumored to include Tinctura in their matrices, granting emotional response capability. Clade public position: theoretical concept not pursued. |
| **Arch-Logician** | Clade apex rank (shared across all three tracks). Despite the Command-sounding name, members from all branches can reach it, though Command dominates in practice. |
| **Archivist's Needle** | Clade primary research spire in the Glass Spine. Houses the most sensitive instruments and classified research. Access above the third floor requires Logician approval. |
| **Ashen Ancestors** | Dominant Old Blood faith, the dead reign through inherited memory. Families conduct rituals of ancestral consultation by consuming preserved Tinctura. |
| **Assayer's Row** | Independent memory assessors in the Grand Rib-Market who evaluate quality, authenticity, and degradation state. The closest thing the Market has to neutral authority. |
| **Athanor (Tier 7)** | Mythic "world memories" beyond verifiable record. If real, they can change eras; if false, they can still start wars. |
| **Athanor (rank)** | Conclave rank 5, living legend. Works achieve Consonance. Perhaps a dozen living Athanors exist at any given time. |
| **Bargemen** | A neutral guild controlling canal transport, tolls, and cargo flow. Everyone needs them; everyone resents that. |
| **Bleed** | Emotional or contextual spillover that contaminates a memory product during extraction, refinement, or handling. |
| **The Bone Nave** | Largest trading floor in the Grand Rib-Market, built in a natural cavern where Aethos formations create a vaulted ceiling. High-value auctions occur here. |
| **The Bound** | Conclave rank 1, apprentice bound to a master. Learning to sense spiritus. Cannot sell work. |
| **The Break** | A gap in the Char ruins where a collapsed building exposed a previously sealed Old Blood vault. Empty when found, or so the official story goes. Hollow Flame symbol. |
| **Calcination** | The extraction of a person's Quintessa (Tier 6, core identity). Named for the alchemical process of heating a substance until reduced to powder. In Gloamvere, the metaphor is inverted: the "essence" is ripped out, the empty vessel remains. Not death, an unmaking. |
| **Calx** | The neurological and psychic trace remaining in a person who has been calcined, the faint echo that allows a Dreg to maintain autonomic function despite total absence of identity. Whether calx is recoverable, programmable, or spiritually significant is one of the most contested questions in Gloamvere City. |
| **Canal Drift** | Refinery runoff that becomes ambient emotional residue in the canals and downstream districts; usually contextless, sometimes anomalously structured. |
| **Canalborne** | Gloamvere community, raised on the waterways by neutral guild families. Feature: Current Reader. |
| **Caput Mortuum** | Endpoint waste after repeated burn/consumption/refinement cycles. Useful as fuel and industrial filler; worthless as experience. Burned in lamps producing the city's ancestral grey-violet glow. |
| **Cerebral Overload** | Risk of consuming a memory more than 2 tiers above one's tolerance. Can stun, fracture attention, or induce panic/shock. |
| **The Char** | Contested ruins of a neighborhood destroyed by fire two generations ago (~440–460 post-displacement). De facto Hollow Flame territory. |
| **Charborne** | Gloamvere community, raised in the Char outside formal power structures. Feature: Scrapcraft. |
| **Clade, Siderian** | One of the three major factions. Treats memory as a knowable phenomenon; builds infrastructure, constructs, and classification systems. Three internal tracks: Scholars, Engineers, Command. |
| **Clear (degradation grade)** | A memory that has circulated lightly: minor blur but intact meaning. |
| **Command (Clade track)** | The political/military leadership track within the Siderian Clade. Controls funding, classification, and construct deployment. Structural advantage in promotions to Arch-Logician. |
| **Conclave, Spiritus** | One of the three major factions. Treats memory as living spiritus; crafts vessels and infused goods; frames extraction as giving memory a home. |
| **Consent Spectrum** | The setting's graded model for extraction consent (Willing → Transactional → Coerced → Forced). Quality, stability, and ethics all track with this. |
| **Consonance** | The pinnacle of Conclave craft, a state where object and memory are so well-matched that the result exceeds what either could be alone. A Consonant masterwork has presence and opinions. Achieving Consonance elevates a Resonant to Athanor. |
| **Construct** | An engineered chassis powered by stabilized memory patterns (often Amalga) designed to perform tasks without fatigue; intentionally missing a true self. |
| **Construct Control Rods** | Clade command tool. Brass rods loaded with command-authorized Amalga that override construct programming. Rank-keyed. |
| **Construct Yards** | Clade open-air engineering bays for automaton assembly, testing, and repair. Kept deliberately visible. |
| **Consumption** | The act of uncorking a memory vial and inhaling the "smoke." Absorption is instantaneous. The user does not just "watch" the memory, they *live* it. For a split second, they *are* the person who made the memory. |
| **Courier** | A neutral or semi-neutral delivery operator. Couriers are trusted when no one trusts a rival faction's communications. |
| **Crucible (sealed)** | A high-grade container for long-term storage of high-tier memory (especially Tinctura) designed to reduce contamination and degradation. |
| **Cult of the Fractured Mirror** | Worshipers of Lady Nyxentia who infiltrated Arche at its zenith. Despised Archean order. Performed the Rite of Unmaking on the night of the High Tide Festival. Annihilated at ground zero in the Marrow Vault, no survivors, no memory artifacts. |
| **The Displacement** | The event that ripped Gloamvere City from Arche and deposited it into Kavath. Caused by the Rite of Unmaking interacting with the Aethos burial grounds and the Archean people's will. |
| **Distillation** | Pipeline stage where memory is refined, separated, and graded; can stabilize product or strip context for utility. |
| **Dissolution** | Pipeline stage of extraction: the process by which memory leaves a person and becomes substance. |
| **Distorted (degradation grade)** | Heavy circulation. Emotional bleed and contamination. Key facts drift or become wrong. |
| **Dredge-Canals** | A downstream district zone defined by canal waste, poor filtration, Drift exposure, and weak law enforcement. |
| **Dreg** | A person whose Quintessa has been extracted via Calcination. A living body with no ego, breathing, walking if directed, eating if fed. Common slang. See also: Husk. |
| **Dreg Condition** | 3-stage gameplay mechanic: Fraying → Eroding → Calcined. See Part XI, Custom Daggerheart Mechanics. |
| **Dregborne** | Gloamvere community, shaped by proximity to the calcined. Feature: Holdfast. |
| **Dregs Walk** | Phenomenon where groups of Dregs move through the Dredge-Canals in aimless, synchronized patterns no one can explain. |
| **Drift** | The symptomset: emotional bleed, sensory flashes, intrusive affect from memory exposure. |
| **Canal Drift** | Drift driven by refinery runoff in city waterways. |
| **Wild Drift** | Drift driven by ambient memory saturation outside the city in the memory wilderness. |
| **Environmental Drift** | The tendency for carried memories to resonate with ambient instability on Unmoored Paths and near Thin Spots, degrading faster than normal. |
| **Dynastic Houses** | Old Blood houses that use sacredness as political leverage, hoarding Quintessa as capital. |
| **Eidolon Compass** | A Conclave-crafted instrument used to locate a memory's emotional core and stabilize orientation during Anchoring. Resembles a pocket watch with no clock face. |
| **Ember Nave** | Ruined chapel in the Char repurposed as a Hollow Flame gathering hall. Walls painted with the movement's iconography. |
| **Engineers (Clade track)** | The applied research track within the Siderian Clade. Build constructs, infrastructure, and refinery systems. |
| **Era of Calamities (The Forging)** | Three catastrophic events during Arche's pre-displacement history that shaped Gloamverei cultural identity: The Summer of Silver Bellies, The Pyre of Stone, The Year of the Glass Rain. |
| **Essentia** | An addictive emotional byproduct of Clade industrial refinement, pure intensity without narrative, context, or identity. Not a currency tier. Classified as controlled industrial waste; leakage fuels the city's worst addiction crisis. |
| **Exalted Scion** | Old Blood rank 5, house head, Council seat. Speaks with the authority of their entire ancestral line. |
| **Factionborne** | Gloamvere community, raised inside a faction's institutional structure. Feature: Institutional Knowledge. |
| **Factor (construct class)** | A common construct class: maintenance/logistics units running single-skill Amalga loops. |
| **Factor (rank)** | Clade Engineer track, rank 2. |
| **Faded (degradation grade)** | Multiple circulations. Faces genericize. Dialogue paraphrases. Sensory detail dulls. |
| **Faithful Houses** | Old Blood houses driven by genuine belief, maintaining open temples and funding Lahkriman Shroud-Bearers. |
| **Fellow** | Clade Scholar track, rank 3. Senior researcher with full publication authority. |
| **First Kindling** | Conclave apprentice ceremony, first unassisted infusion. A public event in the workshop. |
| **First Kindling Hall** | Where Conclave apprentices undergo their First Kindling ceremony. Saturated with decades of accumulated pride, anxiety, and relief. |
| **Fracturers** | The radical wing of the Hollow Flame. Break preservation seals on hoarded memories to release them into circulation. |
| **Fragmentborne** | Gloamvere community, raised in a Fragment settlement outside Gloamvere City. Feature: Outsider's Eye. |
| **Fragments** | Stratum 2 of Kavath: displaced communities, ruins, and settlements pulled into Kavath from Arche or other planes over the centuries. |
| **The Fraying** | The downstream edge of the Loom-Spires where the district bleeds into poorer neighborhoods. Shaper territory. |
| **Gate of Thousand Names** | Memory-infused obsidian archway at the Ossuary entrance, etched with the genealogy of every noble house. |
| **Glass Spine** | Siderian Clade territory district: laboratories, administration, sky-tunnels, and construct infrastructure. |
| **Kavath** | The demi-plane of permanent twilight where Gloamvere City exists after displacement; enclosed by the Veil. Three strata: Memory Wilderness, Fragments, Aethos Substrate. |
| **Gossamer Bridge** | Wide Conclave thoroughfare connecting three artisan islands, woven from memory-strengthened fibers. Resonates with a sense of belonging. |
| **Grand Rib-Market** | Neutral trade hub district built around exposed Aethos formations; politically neutral by necessity. |
| **Grey Market** | Semi-permanent Dredge-Canals market trading exclusively in Leached and Faded memory. Where memory goes to die. |
| **High Tide Festival** | The celebration during which the Rite of Unmaking was performed, the last night before displacement. |
| **Hollow Flame** | Old Blood heretical reform movement. Argues that if memory is sacred, it belongs to everyone. Deliberately has no ranks. Ranges from nonviolent moderates to radical Fracturers. |
| **Husk** | Clinical Clade term for a person whose Quintessa has been extracted. See: Dreg. |
| **Gloamvere (Gloamvere City)** | The city. Displaced from Arche into Kavath by the Rite of Unmaking. Same name in both eras, the inhabitants didn't rename their home; they adapted it. A canal city of white stone darkened by age, gothic spires, and memory-fueled industry. Motto: *"Adversa non frangunt"*, Adversity does not break us. |
| **Kindle** | Conclave rank 2, completed first solo infusion. May sell work under master's mark. |
| **Kindling (era)** | Historical period (~40-120 post-displacement) when memory was recognized as substance and the proto-factions formed. |
| **Lady Nyxentia** | The Mistress of Discord worshiped by the Cult of the Fractured Mirror. A figure associated with chaos, entropy, and the dissolution of order. Whether mortal or entity predating the cult remains an open question. |
| **Lahkrima** | Old Blood faith focused on compassion and grief, "The Veiled Mercy." The Shroud-Bearers of Lahkrima serve as memory-bearers, consuming Tinctura of sorrow from those who cannot carry it. The reason the Old Blood retains popular legitimacy. |
| **Lahkrima Nave** | The largest Lahkrima temple in Gloamvere City. Open to all, including Dregs. |
| **The Law of Blood** | Old Blood border mechanism. Ossuary structures are infused with ancestral Tinctura; recognized bloodlines navigate normally while unrecognized visitors experience navigational nightmares. |
| **Leached (degradation grade)** | Near-collapse. A "grey" memory; context mostly gone. Often sold as low-grade lamp stock. |
| **Leach Line** | Unofficial border in the Grand Rib-Market where legitimate trade ends and black-market activity begins. |
| **Living Memory** | Clara Moree's experimental research: calx-based substrates that grow memory the way soil grows plants. Early stage, producing Volatilis-grade fragments with no identifiable origin. |
| **Living Reliquary** | Old Blood rank 4, has permanently consumed ancestral Quintessa. Speaks with voices not entirely their own. |
| **Locked Archive** | Clade classified research vault. Scholars whose work ends up here receive a commendation and lose control of their findings. |
| **Logician** | Clade Command track, rank 3, senior strategist with classification authority. |
| **Loom-Spires** | Spiritus Conclave territory district: craft towers, workshops, and the artisan heart of the city. Name is historical (original weaving tradition). |
| **Lumen (construct class)** | The simplest construct class: sealed light chambers. Ubiquitous in Clade territory. |
| **Luminary** | Clade rank 4 (shared), division head. |
| **Marrow Vault** | The deepest crypt beneath Gloamvere City, where the Cult of the Fractured Mirror performed the Rite of Unmaking. Sealed since the displacement. A void in Gloamvere City's historical record, no memory artifacts survive from the moment of casting. |
| **Memory Bleed** | Cross-contamination of emotional content between a memory and its handlers. Occurs prominently at the Distorted degradation level. |
| **Memory Wilderness** | Stratum 1 of Kavath: wildland where memory vapor thickens into phenomena, predators, and emotional weather. |
| **Nigredo Pans** | Broad shallow basins used in Conclave refineries to drive off volatile sensory fragments during upward refinement. |
| **Novitiate** | Clade rank 1 (shared), entry rank. Rotates through all three tracks before specializing. |
| **Null-Mortar** | A binding agent from crushed abjuration crystals, developed during the Pyre of Stone calamity. Pre-displacement engineering. |
| **Observer** | Clade Scholar track, rank 2. Independent researcher with publication rights. |
| **Old Blood Council** | One of the three major factions. Treats memory as sacred inheritance; controls vaults, lineage authority, and historical authentication. |
| **Ossuary Isles** | The original lagoon islands on which Gloamvere City was built, the Tumuli of the Aethos. Foundation of both the city and Old Blood territory. |
| **Overwrite** | The risk of consuming a Quintessa. The consumer must win a contest of wills, or the consumed personality takes control of the host body. |
| **Paradox Room** | Cross-faction debate hall in the Unmoored Commons, maintained by Clade Scholars. |
| **Patina / Stirring** | Long-term drift effect in constructs: emergent quirks and behavior resembling personality. Clade calls it Patina (maintenance issue); Conclave calls it Stirring (the spiritus responding). |
| **Precipia (Tier 4)** | Semantic memory: objective facts/expertise; highly stable and valuable. |
| **Precipitate Slag** | Chalite-grey powder with no discernible memory content; byproduct of refinement. Used as additive in mortar, bindings, and canal filtration. |
| **Preservation Rite** | See Anchoring. Performed at a Thin Spot with tools and a catalyst memory to lock a memory's current state. |
| **Pristine (degradation grade)** | First-hand, never circulated. Perfect clarity. |
| **Pyre of Stone** | Second Arche calamity: magical resonance caused the Sea Wall's granite to ignite with cold purple flames. Response: the Mason's Guild developed Null-Mortar. |
| **Quintessa (Tier 6)** | Identity memory: deep continuity of self; priceless and dangerous to extract or consume. |
| **Reliquarian** | Old Blood rank 3, entrusted guardian of vaults, temples, and ancestral collections. |
| **Reliquarian's Walk** | Narrow corridor of bloodline-keyed vault doors beneath the Silent Ossuary. Whoever controls the Walk controls access to ancestral memory. |
| **Remnant** | Old Blood rank 1, unrecognized servant or outsider. Essential to operations, invisible in politics. |
| **The Reminiscent** | Old Blood rank 2, formally recognized member. Junior clergy, ritual assistants, recognized heirs. |
| **Residuum** | The most well-known tavern in the Unmoored Commons. Named for "what remains after the process is complete." One rule: no extraction on the premises. |
| **Resonance Bells** | Conclave communication network using memory-infused bells that transmit emotional signature alongside sound. |
| **Resonance Keys** | Conclave border tool. Tokens carried by authorized individuals that neutralize Woven Wards. Tuned to specific networks. |
| **Resonance Posts** | Public/neutral messaging nodes using calibrated tonal codes. Gloamvere City's closest analogue to a telegraph. |
| **Resonant** | Conclave rank 4, senior master. Recognized for exceptional intuition in memory-vessel matching. |
| **Rite of Unmaking** | The night Gloamvere City was torn from Arche and displaced into Kavath. "Rite of Dissonance" is the cult's ritual name; "Rite of Unmaking" is what history calls the event. |
| **Scars (area-scale)** | Larger, unstable Veil boundary failures, shears rather than doors. Can take chunks of territory (fields, blocks, villages). Rarer and messier than Thin Spots. |
| **Scholars (Clade track)** | The pure research track within the Siderian Clade. Driven by curiosity; cannot control what happens to their work once Command classifies it. |
| **Shapers** | Conclave pragmatists, work with market-available memory of any provenance. |
| **Silent Ossuary** | Old Blood Council territory district: vault-chapels, preservation halls, cold stone, chanting Reminiscent. |
| **Solvate (Tier 2)** | Working memory: passing thoughts, partial ideas, unstable. |
| **Spent / Ashing** | Not a tier, an observed condition where repeated burn/processing leaves only inert residue. Precedes Caput Mortuum. |
| **Spiritus** | Conclave framing of memory as a living essence with willful behavior patterns. |
| **The Still** | Hidden distillery in the Dredge-Canals where black-market operators refine Leached dregs back into Volatilis. Moves regularly. |
| **Summer of Silver Bellies** | First Arche calamity: the ocean recoiled, the harbor filled with deep-sea carcasses, plague turned skin to grey scale. Response: filtration masks, alchemical preservatives, record export year. |
| **"Sunned"** | Common slang for outsider, refers to sun-marked humans from Fragments or Thin Spot arrivals who are visibly different from pale, dark-eyed native Gloamvereis. |
| **Tenders** | Conclave purists, only work with freely given memory. |
| **Thin Spots** | Structured, threshold-scale weaknesses in the Veil (doorframes, archways, open graves, empty rooms). Traversable passages that behave like doors. Used for Preservation rituals and planar travel. |
| **Tinctura (Tier 5)** | Episodic memory: a specific lived event with emotional context; traded by contract and provenance. |
| **Tinctura Intensity Modifiers** | Value of Tinctura is modified by emotional content: Low Arousal (stable, low value), Mid Arousal (moderate), High Arousal (volatile, high value), Conflicted (very unstable, discounted). |
| **Transactional Consent** | The most common commercial extraction band: consent motivated by need; product functional but carries instability. |
| **Unmoored Commons** | Cross-faction neutral ground district: taverns, coffeehouses, debate halls, and informal meeting spaces along bridge-heads where faction territories intersect. The natural hub for quest hooks and cross-faction NPC encounters. |
| **Unmoored Paths** | Bridges and canal-ways between districts where no single faction's influence fully holds. Travelers keep memory vials corked to prevent Environmental Drift. |
| **Vastus Hinterlands** | Agricultural plains, mountain passes, and mining communities upriver from Gloamvere City's former location in Arche. |
| **Veil** | Semi-permeable membrane enclosing Kavath; raw contact is lethal/unrecoverable; Thin Spots act as structured doors. Weakens at thresholds and responds to intention. |
| **Veilborne** | Gloamvere community, came through the Veil from Arche or another plane. Feature: Liminal Sense. |
| **Vigil (construct class)** | Border patrol/security construct class: multi-skill Amalga load, reactive criteria enforcement. Easy to fool if you know the criteria; impossible to reason with if you don't. |
| **Volatilis (Tier 1)** | Sensory memory: fleeting sensations (scent, sound, color). Evaporates quickly. Base-unit market currency. |
| **Wellkeepers** | Neutral guild operating wells and potable water distribution; charter-enforced neutrality. |
| **Woven Wards** | Conclave emotional barrier installations. Banners and bridge-mounted elements infused with high-intensity Tinctura of unwelcome or dread. Neutralized by Resonance Keys. |
| **Wright** | Conclave rank 3, full artisan (prefix = craft specialty: Threadwright, Smithwright, Lampwright, Luthwright, Masonwright, Phialwright, etc.). |
| **Year of the Glass Rain** | Third Arche calamity: atmospheric anomaly caused rain to freeze into razor-sharp shards. Response: reinforced glass sky-tunnels and expanded crypt-tunnels. Trade never stopped. |

## Deprecated Terminology

The following terms from the v1 glossary have been formally replaced:

| Deprecated Term | Replaced By | Notes |
|---|---|---|
| Taper | Volatilis | Tier 1 memory |
| Ember | Solvate | Tier 2 memory |
| Flame | Amalga | Tier 3 memory |
| Blaze | Precipia | Tier 4 memory |
| Inferno | Tinctura | Tier 5 memory |
| True Name | Quintessa | Tier 6 memory |
| *(no equivalent)* | Athanor | Tier 7 (new) |
| Hollowing | Calcination | Identity extraction process (not the Dreg Condition stage; Stage 2 was renamed to **Eroding**) |
| Gutterborn | Dreg / Husk | Person whose Quintessa was extracted |
| Weaver's Conclave | Spiritus Conclave | Artisan faction |
| Vestigium Flames | Caput Mortuum | Leached memory fuel, now designated by the alchemical term for distillation waste |
| Heart of the Titan | The Marrow Vault | Deepest Aethos crypt, renamed to align with Aethos anatomical motif |
| Fluctuat nec Mergitur | Adversa non frangunt | Arche's motto, replaced with original for publication safety |
