# System Reference Document 5.2.1

The markdown files in this directory are converted from the System Reference
Document 5.2.1 PDF (https://www.dndbeyond.com/srd), one file per chapter and one
per class, reformatted for retrieval. The modifications are listed in NOTICE.md.
Regenerate these files with `scripts/convert_srd.py` (see its docstring).
